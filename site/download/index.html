Most of these files are downloaded from SourceForge; the rest are still on GitHub for now. The checksum is the same wherever you get a file. The checksums are also in SHA256SUMS (melon 0.2), SHA256SUMS (i686-20261007).

Check it

A download can break on the way, and a checksum tells you whether yours is whole. Compare the result with the SHA-256 above.

# Linux and macOS
sha256sum melon-desktop-20260929-x86_64.iso
# or, with SHA256SUMS next to the files
sha256sum -c --ignore-missing SHA256SUMS

# Windows (PowerShell)
Get-FileHash melon-desktop-20260929-x86_64.iso -Algorithm SHA256

Write it to a USB stick

Use Rufus, balenaEtcher or Ventoy, or on Linux:

# replace sdX with your stick, and check with lsblk first: dd overwrites it
doas dd if=melon-desktop-20260929-x86_64.iso of=/dev/sdX bs=4M status=progress conv=fsync

Keeping Windows? Shrink it first and leave at least 20 GB free: the install steps. Older releases are on the releases page.
